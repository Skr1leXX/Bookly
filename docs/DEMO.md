# Сценарий демонстрации

Время: 10–15 минут. Все данные вымышленные. Ожидаемый результат указан в каждом шаге.

## Подготовка

- **А. Облачный демо-проект:** выполнены миграции и `seed.sql` ([DEPLOY.md](DEPLOY.md)); пароль демо-аккаунтов вам выдали отдельно.
- **Б. Локально без Supabase:** `npm run emulator` и `npm run dev` ([README](../README.md#без-supabase-локальный-стенд)); пароль локального seed указан в [supabase/README.md](../supabase/README.md).
- **В. Без готовых аккаунтов:** зарегистрируйтесь на `/register` (создастся ваша пустая организация). Шаг 2 («Клиент») и шаги 3–5 вы выполните с нуля; на шаге 6 используйте ссылку из «Настроек».

## 1. Авторизация

1. Откройте защищённую страницу (например, `/clients`) без входа → перенаправление на `/login`.
2. Введите неверный пароль → «Неверный email или пароль», email остаётся в поле.
3. Войдите как `alina@bookly.test` → дашборд («Добрый день, Алина»), в шапке роль «Владелец».
4. Меню профиля → «Выйти» → снова `/login`.
5. Роли: войдите как `anna@bookly.test` → в меню нет «Настройки», на «Услугах» нет кнопок изменения, у клиентов нет кнопки удаления и экспорта.

## 2. Добавление клиента

1. Войдите как владелец или администратор → «Клиенты» → «Добавить клиента».
2. Нажмите «Добавить» с пустой формой → под полями «Укажите имя», «Укажите телефон».
3. Введите телефон `abc` → «Некорректный телефон»; введённое не стирается.
4. Имя «Демо Клиентов», телефон `+7 (900) 111-22-33` → клиент в списке с пометкой «Новый».
5. Введите «Демо» в поиск → остаётся одна строка. Откройте клиента → страница с историей («У клиента пока нет записей»).

## 3. Создание услуги

1. «Услуги» → «Добавить услугу»: название «Демо-услуга», длительность 60, цена 2000, категория «Демо».
2. Цена `-10` → «Цена не может быть отрицательной».
3. Сохраните → карточка с «60 мин» и «2 000 ₽». «Отключить» → бейдж «Отключена»; «Включить» возвращает «Активна».

## 4. Добавление сотрудника

1. «Сотрудники» → «Добавить специалиста»: имя «Демо Мастер», отметьте «Демо-услуга».
2. Расписание: оставьте Пн–Пт 10:00–19:00; для понедельника укажите перерыв 13:00–14:00. Перерыв вне рабочего времени (например, 20:00–21:00) → «Перерыв должен быть внутри рабочего времени».
3. Сохраните → карточка с «Пн–Пт, 10:00–19:00» и услугой «Демо-услуга».

## 5. Создание записи

1. «Записи» → «Новая запись»: клиент «Демо Клиентов», услуга «Демо-услуга», специалист «Демо Мастер», дата — ближайший вторник, время 10:00 → «Создать запись». В списке запись со статусом «Подтверждена».
2. Вторая запись на 10:30 → предупреждение «Время занято», после отправки «Это время у специалиста уже занято другой записью». Время 11:00 (встык) создаётся.
3. Время 13:30 в понедельник → «У специалиста перерыв».
4. Меню строки («⋯») → «Отменить запись» → статус «Отменена», время снова свободно.
5. «Календарь» → нужная неделя: запись на месте; перетащите блок на другое время (мышью) — запись переносится; на занятое время или в перерыв — сообщение об отказе.

## 6. Публичная онлайн-запись

1. «Настройки» → блок «Онлайн-запись» (для демо-салона `/book/lavanda-demo`). Откройте ссылку в другом окне или на телефоне, без входа.
2. «Женская стрижка» → «Анна Ковалёва» (или «Любой специалист») → дата (вторник) → время. В списке нет перерыва 13:00–14:00 и занятого времени.
3. Контакты: оставьте пустыми → ошибки; введите `+7 (900) 123-45-67`, `demo@example.com` → «Далее».
4. Проверьте сводку → «Подтвердить запись» → страница «Запись создана» с услугой, мастером, временем и адресом (без ваших контактов).
5. В админ-панели: в «Записях» новая запись с бейджем «Онлайн» и статусом «Ожидает подтверждения»; в «Календаре» она на своём месте; в колокольчике — «Новая онлайн-запись».
6. Снова откройте запись на то же время → оно больше не предлагается. Если время заняли, пока вы заполняли форму, будет сообщение «Это время только что заняли» и кнопка выбора другого времени.

## Что считать успехом

Все шаги выполняются без ошибок на странице и в консоли браузера, данные сохраняются (обновите страницу — они на месте), онлайн-запись видна администратору.
